# 🏫 CampusTrack – Intelligent Lost and Found Locator

**CampusTrack** is an intelligent, AI-powered web application that streamlines the process of reporting, managing, and retrieving lost and found items within a campus.  
It provides an easy-to-use interface for students, faculty, and administrators to report items, view matches, and communicate in real-time — ensuring no lost item stays lost for long.

---

## 🌟 Overview

CampusTrack bridges the gap between people who **lose** items and those who **find** them using intelligent matching, modern UI, and efficient communication tools.

---

## 🚀 Key Features

### 🧠 Smart Item Matching
- Uses Natural Language Processing (NLP) to intelligently match lost and found reports.
- Suggests similar items automatically to speed up recovery.

### 💬 Real-Time Communication
- Integrated chat module for direct communication between users.
- Broadcast feature for notifying everyone about found items.

### 🗂️ User-Friendly Design
- Built with **React.js** for a clean and responsive interface.
- Easy navigation between reporting, viewing, and managing items.

### ⚙️ Powerful Backend
- Developed using **Spring Boot** and **RESTful APIs**.
- Provides secure, scalable, and efficient data management.

### 🧭 Location Tracking
- Allows users to specify exact or approximate locations where items were lost or found.
- Enhances accuracy in item searching and filtering.
